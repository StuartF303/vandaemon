# VANDIMMER Rev B Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild VANDIMMER-4CH+2A as a 4-layer board with a reworked floorplan, an
on-board antenna, 12 V-capable addressable outputs, and no unrouted pads.

**Architecture:** Schematic changes first (module, polyfuses, connector pin order), then
board setup (stackup, outline, keepouts), then placement, then routing. Placement ends at
a hard visual-verification checkpoint before any copper is laid.

**Tech Stack:** KiCad 10, Konnect MCP, `kicad-cli`, the project's Python tooling in
`hw/VDDimmer/tools/` (run with KiCad's Python 3.11, **not** the system 3.6).

**Spec:** `hw/VDDimmer/REV-B-DESIGN-2026-09-12.md`

## Global Constraints

- **Never edit `.kicad_sch`, `.kicad_pcb`, `.kicad_pro`, `.kicad_sym`, `.kicad_mod`,
  `fp-lib-table` or `sym-lib-table` as text.** All modifications go through Konnect MCP.
  `.net` is an export and may be regenerated with `kicad-cli`.
- **Verify by read-back.** A Konnect success response is not evidence. Re-query after every
  write. Two documented failures hid behind a success: a zone inserted at the wrong
  indentation, and fields written to unit 1 of a multi-unit symbol.
- **KiCad open vs closed is not interchangeable.** PCB placement and routing need KiCad
  **running** (IPC). Zone inserts and `kicad-cli --save-board` need it **closed**. Batch by
  kind; never both at once.
- **After any KiCad save, re-check anything edited on disk.** A KiCad session once wrote
  back its in-memory copy and silently reverted a board-outline edit, invisible to
  `git diff` because the save landed 53 s before the commit.
- Board ≤ **100 × 100 mm**. Do not shrink below what the layout wants.
- Python for `tools/`: `C:/Program Files/KiCad/10.0/bin/python.exe`
- Commit after every task. Work on branch `vddimmer-rev-b`.

```bash
"C:/Program Files/KiCad/10.0/bin/kicad-cli.exe" sch export netlist \
```

```bash
"C:/Program Files/KiCad/10.0/bin/python.exe" - <<'PY'
import io,re
s=io.open('/tmp/after.net',encoding='utf-8',errors='replace').read()
nets=s[s.index('(nets'):]
conn={}
for b in re.split(r'\n\t\t\(net\b',nets)[1:]:

    if not m: continue
    for r,p in re.findall(r'\(ref "(J[3-6])"\)\s*\n\s*\(pin "([^"]+)"\)',b):

for r in sorted(conn):
    print(r, {k:conn[r][k] for k in sorted(conn[r])})
PY
```
